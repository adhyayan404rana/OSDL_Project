# Hotel Management System — Startup Instructions

This project is a JavaFX application managed by Maven. Follow these steps to set up and run the application.

## Prerequisites
- **Java Development Kit (JDK) 17 or higher**: Ensure Java 17 is installed and configured in your environment.
- **Apache Maven**: Ensure Maven is installed to handle dependencies and build the project.

## How to Run the Project

1. **Open a Terminal**: Navigate to the root directory of the project.
   ```bash
   cd HotelManagementSystem
   ```

2. **Clean and Compile (Optional)**: If you want to ensure a fresh build:
   ```bash
   mvn clean compile
   ```

3. **Start the Application**: Use the JavaFX Maven plugin to launch the GUI.
   ```bash
   mvn javafx:run
   ```

## Project Structure
- `src/main/java`: Contains the Java source code (Models, Controllers, and Utilities).
- `src/main/resources`: Contains the FXML layout files and CSS.
- `app_config.dat`: Local configuration file (Serialized).
- `system_events.log`: Application event log (Binary/RandomAccess).
- `invoices/`: Directory where generated text invoices are stored.

---
*Note: The project currently uses local file persistence. Database integration (Phase 5) is reserved for future implementation.*
