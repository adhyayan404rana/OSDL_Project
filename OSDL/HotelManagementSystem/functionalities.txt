================================================================================
                    HOTEL MANAGEMENT SYSTEM - FUNCTIONALITIES
================================================================================

This document outlines all the current features and functionalities of the 
Advanced Hotel Management System (Enterprise Edition).

================================================================================
1. AUTHENTICATION & ARCHITECTURE
================================================================================
The system is built on an enterprise-grade architecture with role-based access.

- Role-Based Access Control (RBAC): Login system supporting multiple tiers 
  of staff (e.g., ADMIN, MANAGER, RECEPTIONIST).
- Persistent Session State: The active user session is tracked globally across 
  the application.
- Modern Navigation: A unified, persistent sidebar navigation module allowing 
  seamless swapping of application views without opening new windows.

================================================================================
2. DASHBOARD & SYSTEM OVERVIEW
================================================================================
The landing screen providing a high-level overview of hotel operations.

- Live System Clock: Displays real-time clock running on a background thread.
- Real-time Statistics Cards: Total Rooms, Available Rooms, Active Guests, 
  Total Revenue, and Room Types.
- Recent Activity Feed: A live log showing recent system events read continuously 
  from the binary backend audit log.

================================================================================
3. ROOM MANAGEMENT
================================================================================
Advanced inventory cataloging for 7 distinct Room Types (STANDARD to VILLA).

- Auto-filling Metadata: Base tariff, maximum occupancy, and default amenities.
- Amenity Management: Quick-add checkboxes and custom comma-separated fields.
- Interactive Table View: Deep-dive view supporting sorting and filtering.
- State Machine Support: Displays whether a room is AVAILABLE, OCCUPIED, 
  RESERVED, or in MAINTENANCE.
- Sliding Detail Panel & Image Preview.

================================================================================
4. HOUSEKEEPING MODULE
================================================================================
Active management of rooms currently in use or requiring service.

- Status Filtering: Automatically isolates rooms that are OCCUPIED or in MAINTENANCE, 
  hiding rooms that are ready for guests.
- Maintenance Cycles: Staff can mark occupied rooms as 'Needs Maintenance'.
- Room Release: Once cleaned, staff can digitally mark the room as 'Ready', 
  instantly returning it to the 'AVAILABLE' pool for the reception desk.

================================================================================
5. ADVANCED RESERVATION SYSTEM
================================================================================
Robust upcoming booking and conflict prevention engine.

- Booking Form: Captures Guest Name, Phone, Room target, and Date Range.
- Conflict Resolution Engine: Automatically validates Check-In and Check-Out dates 
  against existing bookings for the specified room. Prevents overlapping bookings 
  mathematically (`start1 < end2 && end1 > start2`).
- Auto-Reservation State: If a room is booked for *today*, the system 
  automatically locks the physical room in the catalog as 'RESERVED'.
- Booking Management: View upcoming bookings in a table and cancel them to release 
  the room hold.

================================================================================
6. GUEST MANAGEMENT
================================================================================
Centralized tracking of all individuals checked into the hotel.

- Guest Registry: Tracks metadata including global Customer ID, Assigned Room, 
  and Check-in/Check-out schedules.
- Global Search & Sync: Instant search bars and manual synchronization capabilities.

================================================================================
7. BILLING & CHECKOUT
================================================================================
Handles the financial transaction, customer exit, and invoice generation.

- Customer Intake: Form validation for ID, Name, Phone, and Dates.
- Financial Engine: 
  * Calculates Base Tariff (days * nightly rate).
  * Applies automatic 10% Service Charge and 12% Tax (read from datastore).
  * Discount Codes (e.g., WELCOME10, FIRST25).
- Payment Processing: Dropdown selection for Payment Mode (Cash, Credit Card, UPI).
- Invoice Generation: Automatically writes a timestamped, highly-formatted text 
  receipt (`.txt`) containing the line-item breakdown and the payment mode.
- Triggers System State Updates (Revenue increases, Room marked OCCUPIED).

================================================================================
8. REPORTING ENGINE
================================================================================
Aggregated system analytics and external export processing.

- Report Generation: Dynamically compiles three distinct reports:
  * Revenue Summary (Total income logs).
  * Guest History (Full registry dump).
  * Room Occupancy Status (Calculated occupancy rate percentages).
- CSV Exporter: Seamlessly converts Java Table View structures into standard 
  Comma-Separated Value (`.csv`) files and saves them with timestamps to an 
  `/exports` directory for external spreadsheet software.

================================================================================
9. SYSTEM & BACKEND UTILITIES
================================================================================
- Automated Event Auditing: Every major action is strictly appended to a 
  `system_events.log` utilizing `RandomAccessFile`.
- Serialization Configurations: Financial rates and settings parsed locally 
  via `ObjectInputStream/ObjectOutputStream`.
